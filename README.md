# Website Performance Analysis using Python

This project analyzes key website performance metrics to evaluate user engagement, session behavior, and traffic trends over time. It was built using Python, pandas, and matplotlib for data analysis and visualization.

## Dataset:
The dataset includes the following metrics per hour:
- Session Primary Channel Group (e.g., Direct, Organic Social)
- Users and Sessions
- Engaged Sessions
- Average Engagement Time per Session
- Engagement Rate and Events per Session

## Tools & Libraries Used:
- Python  
- pandas  
- matplotlib  
- Jupyter Notebook  

## Key Insights:
- Plotted total users and sessions over time to identify peak traffic periods.
- Analyzed engagement metrics like engagement rate, events per session, and average session time.
- Explored correlations between different performance metrics using scatter plots.
- Compared channel-wise performance to identify effective marketing sources.

## Highlights:
- Cleaned and transformed raw CSV data for time series analysis.
- Created line and scatter plots to visualize user engagement behavior.
- Identified which marketing channels brought more engaged users.
- Prepared data for forecasting future session trends using time series modeling.
